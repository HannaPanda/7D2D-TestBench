7DTD Multiversion-Testbench
===========================

Bevor irgendwas: das .NET 10 Desktop Runtime installieren, falls noch nicht da.
    https://dotnet.microsoft.com/download/dotnet/10.0
Ohne das startet keine der beiden Exen.

Dann in diesem Ordner:

    tb.exe init

Das legt testbench.json und die Unterordner an, findet deine gespielte
7DTD-Installation und sagt dir, dass die hier nicht eingetragen werden darf. Ein
Testlauf raeumt jeden fremden Mod aus dem Mods-Ordner weg, und deine Modlist
soll das nicht sein. Das Werkzeug verweigert diesen Ordner auch von selbst.

Danach je Version, die du testen willst, eine eigene Spielinstallation nach
Games\ kopieren (oder mit DepotDownloader holen), dann:

    tb.exe versions scan --add
    tb.exe doctor

Fenster statt Tippen:

    Testbench.Gui.exe

Sprache: oben rechts im Fenster, oder "tb.exe lang english". Vorgabe ist deine
Systemsprache. Die Texte liegen als JSON in lang\ und koennen dort verbessert
werden, ohne etwas neu zu bauen.

Einen Mod anmelden: examples\testbench.mod.json als Muster nehmen, nach
<dein-mod-repo>\test\testbench.mod.json legen, dann

    tb.exe mods add <pfad-dahin>

Alles weitere: README.md, und im Zweifel

    tb.exe doctor

Lizenz: MIT, siehe LICENSE. Benutzen, aendern, weitergeben, auch in etwas
Eigenem; drinbleiben muss nur der Copyright-Hinweis. Ohne Gewaehrleistung.

English

Install the .NET 10 Desktop Runtime first, then run "tb.exe init" in this
folder, put one game installation per version into Games\, and run
"tb.exe versions scan --add". Use "Testbench.Gui.exe" for a window, or
"tb.exe lang english" for English output. Never register the installation you
actually play: a run moves foreign mods out of its Mods folder. The tool refuses
that folder by itself.

Full documentation: README.md and docs\ in the repository,
https://github.com/HannaPanda/7D2D-TestBench
